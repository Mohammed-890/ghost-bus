# Ghost Bus Detector: data

Raw live bus positions (`raw/`), feed health per poll (`health/`), the city timetable cut (`city_gtfs/`), per-day schedules (`schedule/`) and trip-by-trip verdicts (`results/`). Written automatically by the GitHub Actions in the `main` branch.

Contains public sector information licensed under the Open Government Licence v3.0 (Bus Open Data Service).
